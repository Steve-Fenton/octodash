# octodash

Highlights version numbers in the Octopus Deploy dashboard.

## Packaging

To create the zip file for distribution, run:

```bash
pnpm package
```

The zip file will be created in the `dist` folder.

Publishing is still ClickOps. See [How to Create a Browser Extension for Edge or Chrome](https://stevefenton.co.uk/blog/2022/02/how-to-create-a-browser-extension-for-edge-or-chrome/).
